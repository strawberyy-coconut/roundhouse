that `App::swagger()` serves. The version matches the CDN assets used by `App::docs()`.

directory. To update them, download the npm tarball and replace:

- `swagger-ui-bundle.js`
- `oauth2-redirect.html`
- `favicon-16x16.png`
- `favicon-32x32.png`
